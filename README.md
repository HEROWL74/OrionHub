# OrionHub (OrionEngine Launcher)

OrionEngineの導入とプロジェクト作成を簡略化するための専用ランチャーです。  
エンジンのダウンロードから新規プロジェクト作成までを一元化し、開発開始までの手間を大幅に削減することを目的としています。

* **Orion Hub**: プロジェクトイメージ  
![image](https://github.com/user-attachments/assets/f691ddb5-e6c6-41cc-ba0f-dfd7228fe8d3)

---

## 🎯 解決した課題

従来、ゲームエンジンのセットアップには

- 環境構築  
- エンジン配置  
- プロジェクト作成  

など複数の手順が必要でした。

OrionHubではこれらを統合し、  
**誰でも短時間（数分）で開発を開始できる環境を提供**しています。

---

## 📊 成果

14名のテスターに対して検証を行い、  
エンジンダウンロードから新規プロジェクト作成までの時間を測定した結果：

👉 平均 2〜3分で環境構築に成功  

従来の手動セットアップ（約10〜20分程度）と比較して、  
**大幅な時間短縮を実現しました。**

![image](https://github.com/user-attachments/assets/e29d1a3e-c89e-4a3b-a697-89e368f7c149)  
（Google Formによるテスト結果）

この結果から、従来の手動セットアップと比較して、  
開発開始までのハードルを大きく下げることができました。

## 🚀 セットアップ手順

① **インストーラーの実行**  
Releasesから `OrionHub-Setup-1.0.0.exe` をダウンロードし、実行してください。  
インストール完了後、Hubが自動的に起動します。

② **ルートフォルダの設定**  
Hub上部の **[Select Orion Root Folder]** をクリックし、  
プロジェクト保存先（例：`C:\Users\(ユーザー名)\OrionProject`）を選択してください。

③ **エンジンのインストール**  
**[Available Engine Versions]** からバージョンを選択しインストールします。  
ステータスが `(Installed)` になれば準備完了です。

④ **新規プロジェクトの作成**  
**[Create New Project]** にてプロジェクト名などを入力し、作成します。

画面下の **[Your Projects]** に表示されれば、セットアップ完了です。

## 🙌 このプロジェクトについて

本プロジェクトは、OrionEngineの開発と並行して、  
「誰でもすぐにゲーム開発を始められる環境」を実現するために開発しています。

エンジン本体だけでなく、開発環境全体の体験向上にも取り組んでいます。
